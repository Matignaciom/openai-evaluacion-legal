# 📌 Aspectos Relevantes para Revisión Legal

Se recomienda validar especialmente los siguientes puntos durante la revisión jurídica:

- Propiedad intelectual de outputs generados por IA
- Uso comercial permitido
- Responsabilidad sobre contenido generado
- Entrenamiento de modelos con datos del usuario
- Procesamiento y almacenamiento de datos
- Retención y eliminación de información
- Cumplimiento GDPR / privacidad internacional
- Restricciones de uso y contenido prohibido
- Limitaciones de responsabilidad (liability)
- Diferencias entre ChatGPT Consumer, API y Enterprise
- Opciones de exclusión de entrenamiento ("opt-out")
- Protección de datos empresariales
