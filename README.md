## Cómo visualizar los documentos

Ambos archivos están escritos en **Markdown (.md)**. GitHub los renderiza automáticamente como páginas con formato al hacer clic en ellos desde la interfaz web del repositorio.

### Vista previa en GitHub (recomendada)

1. Navega al listado de archivos del repositorio
2. Haz clic en cualquiera de los dos archivos `.md`
3. GitHub mostrará el contenido formateado con títulos, tablas, código, etc.

### Vista previa local

Si clonas el repositorio, puedes abrir los archivos con cualquier editor que soporte Markdown:

- **VS Code**: haz clic derecho sobre el archivo → *Open Preview* (`Ctrl+Shift+V`)
- **Typora**, **Obsidian**, o cualquier visor Markdown
